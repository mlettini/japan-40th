# japan-40th

This is 90% vibe-coded, 10% vibe-engineered app for me to create and view my itinerary for my 40th birthday trip to Japan. The main goals were:

- Make it easy to add/edit the existing itinerary
- Make it easy to scan the plan day-by-day from my phone when out and about
- Highlight important things like where we're staying that day, what's the main activity, and the food plans
- Highlight activities that need attention (e.g. reservation/booking not yet made)
