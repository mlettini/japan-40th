Set up sync

Data lives in a private JSONbin bin so all your devices stay in sync. Paste your Bin ID + Master Key once per device — the same credentials work everywhere.

Where to find these
  1. Sign up at jsonbin.io (free).
  2. Open API Keys in the dashboard and copy your Master Key (starts with $2a$...).
  3. Open Create Bin, set visibility to Private, paste {"days":{},"notes":{},"timeFormat":"24h"} as content, and click Create. Copy the Bin ID from the URL.
